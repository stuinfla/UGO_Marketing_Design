A scholar's portrait cropped into the profile silhouette — the "Meet the Scholars" card.

```jsx
<ScholarCard
  name="Evania Larasati"
  country="Indonesia"
  field="Agrotechnology"
  photoSrc="assets/photos/evania.jpg"
  maskSrc="assets/profiles/p01.png"
  tone="lightTeal"
/>
```

The `maskSrc` profile PNG's alpha crops the photo into the silhouette; `tone` sets the soft halo behind it. Name is Simula, country Simula italic, field David. Group 3 across a row, each with a different `tone`.
