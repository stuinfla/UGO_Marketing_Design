The brand's signature impact statistic — an oversized MD IO number set inside a watercolour profile silhouette.

```jsx
<StatSilhouette
  value="98" unit="%"
  caption="of U-GO scholars advance to the next grade"
  profileSrc="assets/profiles/p03.png"
/>
```

Always pair 2–3 across a row, each on a different campaign hue (use the colored profiles p01–p05). For darker silhouettes set `numberColor="var(--ugo-royal-blue)"` (default) or a beige knockout. `value`/`unit` render the figure; `caption` is the supporting line.
