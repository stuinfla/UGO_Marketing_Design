A pill-shaped call-to-action with an MD IO uppercase label — the brand's standard button.

```jsx
<Button variant="primary" size="lg">Donate</Button>
<Button variant="secondary">Meet the scholars</Button>
<Button variant="subtle">Read more</Button>
```

Variants: `primary` (Royal-Blue fill), `secondary` (outlined ghost), `subtle` (text-only), `onColor` (beige fill, for dark sections). Sizes `sm | md | lg`. Set `pill={false}` for a soft-rect button, `full` to stretch, `as="a"` for links.
