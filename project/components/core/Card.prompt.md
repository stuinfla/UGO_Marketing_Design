A soft, rounded white surface with quiet elevation — the default container for content.

```jsx
<Card>Default white card</Card>
<Card tone="lime">A colored callout</Card>
<Card tone="ink">Dark section card with beige text</Card>
<Card flat pad="md">Grouped list item (hairline, no shadow)</Card>
```

`tone` tints with a campaign hue (`ink` = Royal Blue with beige text). `flat` swaps shadow for a hairline border. `pad`: none · sm · md · lg.
