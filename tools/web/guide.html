Good to know

Can't open links? Turn on web search in that chat and paste the line again.

Using Claude? Turn on Settings → Capabilities → Code execution and file creation so it can make files.

Want changes? Just ask in the same chat: “shorter”, “add a slide on costs”, “make the title slide Royal Blue”.

Check the facts. If the AI adds names, programmes or numbers it found online, confirm them with the U-GO team before sharing.

If something goes wrong

Quick fixes

“I can't open that link”

Turn on web search or browsing for the chat (the “+” or tools button) and paste the line again.

It describes the file but doesn't make one

Reply: “Please create the actual file for me to download.” In Claude, check that Code execution and file creation is on.

It asks you for brand files

Download the brand pack from ugo-brand.netlify.app/brand-pack.zip and attach it to the chat. Don't unzip it.

The fonts look different

PowerPoint and Word show the U-GO fonts only if they're installed on your computer. Otherwise they use close standard fonts. Web pages and PDFs use the real fonts.

Optional · set up once

Never paste the link again

Claude

  1. Download the brand pack: ugo-brand.netlify.app/brand-pack.zip
  2. Settings → Capabilities → turn on Code execution and file creation.
  3. Customize → Skills → Upload skill → choose the zip.
  4. From then on, just type: U-GO: make a 6-slide PowerPoint about [topic].

ChatGPT

  1. Create a Project called “U-GO”.
  2. In the project's instructions, paste:
Follow the U-GO brand at https://ugo-brand.netlify.app/ai for everything in this project.

Chats inside that project are then on-brand automatically.
