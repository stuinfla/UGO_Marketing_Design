Option 2 · best results, 2-minute setup

Add the U-GO skill to your Claude

Gives Claude the real fonts, logos and silhouettes built in, plus a PowerPoint builder. You do this once and it works in every chat.

Download the U-GO skill

  1. Don't unzip the file.
  2. In Claude, click your name (bottom left) → Settings → Capabilities, and turn on Code execution and file creation.
  3. Go to Customize → Skills, click + / Upload skill, and choose ugo-university-design.zip. Make sure it's switched on.
  4. In any chat, start your request with “U-GO:”
U-GO: make a 6-slide PowerPoint for donors about our Nepal programme.

Works on Free, Pro and Max plans. In PowerPoint, the brand fonts only show if they're installed on your computer; otherwise similar standard fonts are used.
