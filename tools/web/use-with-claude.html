Make anything on-brand,

Works in Claude, ChatGPT, Gemini or Copilot. No design skills, no special plan, nothing to install.

1 · Web pages, emails, posts, copy

Paste one line

Copy this into a new chat and change the end to what you need.

Read {{BASE}}/ai and use the U-GO brand to make me a one-page web page for our 2027 scholarship appeal.
…to make me three LinkedIn posts announcing 50 new scholars. …to make me a donor thank-you email about our Nepal programme. …to make me an event poster for our London dinner.

If the AI says it can't open links, turn on web search or browsing in that chat and send the line again.

2 · PowerPoint, Word, PDF

Same line, just ask for the file

Read {{BASE}}/ai and use the U-GO brand to make me a 6-slide PowerPoint about our Nepal programme.

Swap “6-slide PowerPoint” for “two-page Word document” or “one-page PDF”. The AI fetches the logo, silhouettes and colours itself. In Claude, turn on Settings → Capabilities → Code execution and file creation first. PowerPoint shows the brand fonts only if they're installed on your computer; otherwise it uses close standard fonts. Check any facts the AI finds online with U-GO before you share the file.

Only if the AI asks you for brand files: download the brand pack and attach it to the chat without unzipping it.

3 · Claude users: set it up once

Never paste a link again

Add the brand pack as a Claude skill, and every chat knows the brand.

Download the brand pack

  1. In Claude: Settings → Capabilities, and turn on Code execution and file creation.
  2. Customize → Skills → + Upload skill, then choose the brand-pack.zip you just downloaded (don't unzip it).
  3. From then on, just type:
U-GO: make a 6-slide PowerPoint for donors about our Nepal programme.

ChatGPT users: the closest equivalent is a ChatGPT Project. Create one called “U-GO”, add brand-pack.zip to its files, and set its instructions to: Follow the U-GO brand at {{BASE}}/ai for everything.
